01 - dasharray & dashoffset

As propriedades stroke-dasharray e stroke-dashoffset são utilizadas em SVG para criar efeitos de traço em contornos (stroke) de elementos gráficos, como linhas e formas.

stroke-dasharray

Define o padrão dos traços e espaços ao longo de um contorno. É como se você pudesse dizer ao SVG para desenhar uma linha não contínua, mas com segmentos e intervalos.

Exemplo: stroke-dasharray: 30, 50; significa que a linha terá segmentos de 5 unidades de comprimento seguidos por espaços de 10 unidades.

stroke-dashoffset

Controla a posição inicial do padrão de traços definido pelo stroke-dasharray

Exemplo: stroke-dashoffset: 20; desloca o padrão de traço em 20 unidades ao longo do caminho, movendo a posição inicial do padrão.

Animação de Loading

  • Passo 1: Utilize o stroke-dasharray para criar um efeito de "desenho" no elemento e o stroke-dashoffset para manter o segmento inicial do traço sendo exibido 

    
@keyframes {
    from {
        stroke-dashoffset: 0;
        stroke-dasharray: 0 calc(pi * 2 * 50px);
        // calc(pi * 2 * 50px) irá calcular o comprimento da circunferencia criada pelo svg.
        // 50px = raio da circunferência
    }
    to {
        stroke-dashoffset: 0;
        stroke-dasharray: calc(pi * 2 * 50px) calc(pi * 2 * 50px);
    }
}

  • Passo 2: Utilize o stroke-dashoffset novamente para criar um efeito que remova o desenho criado inversamente 

    
@keyframes {
    from {
        stroke-dashoffset: 0;
        stroke-dasharray: 0 calc(pi * 2 * 50px);
        // calc(pi * 2 * 50px) irá calcular o comprimento da circunferencia criada pelo svg.
        // 50px = raio da circunferência
    }
    50% {
        stroke-dashoffset: 0;
        stroke-dasharray: calc(pi * 2 * 50px) calc(pi * 2 * 50px);
    }
    50% {
        stroke-dashoffset: calc(pi * -2 * 50px);
        // Número negativo para que o efeito se mova na direção contrária
        stroke-dasharray: calc(pi * 2 * 50px) calc(pi * 2 * 50px);
    }
}

  • Passo 3: Rotacione o elemento 

    
@keyframes {
    from {
        stroke-dashoffset: 0;
        stroke-dasharray: 0 calc(pi * 2 * 50px);
        // calc(pi * 2 * 50px) irá calcular o comprimento da circunferencia criada pelo svg.
        // 50px = raio da circunferência
        transform: rotate(0deg);
    }
    50% {
        stroke-dashoffset: 0;
        stroke-dasharray: calc(pi * 2 * 50px) calc(pi * 2 * 50px);
    }
    50% {
        stroke-dashoffset: calc(pi * -2 * 50px);
        // Número negativo para que o efeito se mova na direção contrária
        stroke-dasharray: calc(pi * 2 * 50px) calc(pi * 2 * 50px);
        transform: rotate(360deg);
    }
}
