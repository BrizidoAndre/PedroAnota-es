01 - Slider CSS

Artigo explicativo sobre a criação de um slider funcional com CSS & JS (opcional)

Estrutura HTML

Para a criação desse projeto o HTML será composto por três partes: container, wrapper e slides

                        
<div class="container">
    <div class="wrapper">
        <div class="slide"></div>
        <div class="slide"></div>
        <div class="slide"></div>
    </div>
</div>

CSS

Estilização do componente

  • Passo 1: Defina o tamanho do container & adicione uma cor para visualizar melhor (opcional). Além disso, remova a exibição de elementos filhos que ultrapassem seus limites (overflow: hidden)

                            
.container{
    width: 100%;
    height: 400px;
    background: coral;
    overflow: hidden;
}

  • Passo 2: Defina o tamanho do wrapper para possuir a altura do container e a largura do container multiplicada pelo número de slides. Além disso, defina a margem para 0 (margin: 0;).

                            
.wrapper-ex {
    height: 100%;
    width: calc(100% * 3);
    display: flex;
}

  • Passo 3: Adicione os slides com o tamanho total do container (altura e largura). Estilize as imagens para encaixarem no tamanho de slide (opcional, depende do que será exibido em cada slide)

                            
.slide {
    height: 100%;
    width: 100%;

    img {
        width: 100%;
        height: 100%;
        object-fit: cover;
    }
}

  • Passo 4 (opcional): Crie uma animação que manipule o slider. A propriedade margin-left negativa serve para criar o efeito de slide

                            
.animated-wrapper {
    animation: ease-in-out 10s infinite alternate animated-wrapper;
}

@keyframes animated-wrapper {
    from {
        margin-left: 0;
    }
    20% {
        margin-left: 0;
    }
    30%{
        margin-left: -100%;
    }
    70% {
        margin-left: -100%;
    }
    80% {
        margin-left: -200%;
    }
    to {
        margin-left: -200%;
    }
}

Tornando funcional - CSS

Tornando-o um slider dinamicamente navegável.

  • Passo 1: Crie elementos "checkbox" 

                            
<div class="container">
    <div class="wrapper">...</div>
    <div class="controllers">
        <label id="controller-1" class="controller">
            <input checked type="radio" name="slider-selector" />
        </label>
        <label id="controller-2" class="controller">
            <input type="radio" name="slider-selector" />
        </label>
        <label id="controller-3" class="controller">
            <input type="radio" name="slider-selector" />
        </label>
    </div>
</div>

  • Passo 2: Customize a exibição do slider de acordo com o elemento selecionado e adicione position: relative; ao container para garantir que o próximo passo funcione corretamente. Além disso, adicione uma duração de transição no wrapper (transition-duration: 1s;) 

                            
.container{
    position: relative;
}
.checkbox-wrapper{
    --current-index: 0;
    transition-duration: 1s;
    margin-left: calc(-100% * var(--current-index));
}

.container:has(#controller-1 input:checked) .checkbox-wrapper {
    --current-index: 0;
}

.container:has(#controller-2 input:checked) .checkbox-wrapper {
    --current-index: 1;
}

.container:has(#controller-3 input:checked) .checkbox-wrapper {
    --current-index: 2;
}

  • Passo 3: Estilize os elementos checkbox para se manterem na tela e parecerem mais com seletores e voila!

                            
.controllers{
    position: sticky;
    width: 100%;
    bottom: 0;
    left: 0;
    display: flex;
    align-items: center;
    justify-content: center;
    padding-bottom: .25rem;
    gap: 2rem;
}

.controller{
    height: 15px;
    width: 15px;
    border-radius: 50%;
    border: 2px solid white;
    cursor: pointer;

    input {
        display: none;
    }
}

.controller:has(input:checked){
    background: white;
}

Tornando funcional - JS

Tornando-o um slider dinamicamente navegável.

  • Passo 1: Crie botões para a navegação entre slides (next e prev)

                            
<div class="container">
    <div class="wrapper">...</div>
    <div class="action-btns">
        <button>Previous</button>
        <button>Next</button>
    </div>
</div>

  • Passo 2: Adicione uma variável CSS que permita alterar a margem do wrapper dinamicamente & um tempo de transição (transition-duration: 1s;). Além disso, adicione o position: relative; ao container 

                            
.container{
    position: relative;
}
.checkbox-wrapper{
    --current-index: 0;
    transition-duration: 1s;
    margin-left: calc(-100% * var(--current-index));
}

  • Passo 3: Estilize os botões para aparecerem na tela e terem um efeito de desabilitado quando estiverem nesse estado

                            
.action-btns {
    position: sticky;
    width: 100%;
    bottom: 0;
    left: 0;
    display: flex;
    align-items: center;
    justify-content: center;
    padding-bottom: .5rem;
    gap: 2rem;

    button{
        padding: 0.5rem 1rem;
        background: darkblue;
        color: white;
        border: none;
        border-radius: .75rem;
    }

    button:disabled {
        opacity: .75;
    }
}

  • Passo 4: Adicione o seguinte código javascript (seguindo as instruções dos comentários) para a manipulação de slides e voila!

                            
// Adicione um id ao wrapper para referenciar ele e seus slides
const wrapper = document.getElementById('wrapper-1')
const slides = document.querySelectorAll("#wrapper-1 .slide-ex")

// Adicione um id aos botões de ação
const prevBtn = document.getElementById('action-prev-1')
const nextBtn = document.getElementById('action-next-1')

// Adicione uma função que retorne o index atual do slide
function getIndex() {
    return isNaN(parseInt(wrapper.style.getPropertyValue('--current-index'))) ? 0 : parseInt(wrapper.style.getPropertyValue('--current-index'))
}

// Adicione uma função que realize as atividades necessárias ao alterar o slide atual (Desabilitar botões caso preciso & mudar o valor da variável CSS)
function changeIndex(index) {
    console.log(slides.length)
    if (index > 0) {
        prevBtn.removeAttribute('disabled')
    } else {
        prevBtn.setAttribute('disabled', 'disabled')
    }
    if (index < slides.length - 1) {
        nextBtn.removeAttribute('disabled')
    } else {
        nextBtn.setAttribute('disabled', 'disabled')
    }

    wrapper.style.setProperty('--current-index', index)
}

// Defina um valor inicial e chame a função
changeIndex(getIndex())

// Adicione eventos js para a alteração do index atual
nextBtn.addEventListener('click', () => {
    changeIndex(getIndex() + 1)
})

prevBtn.addEventListener('click', () => {
    changeIndex(getIndex() - 1)
})
